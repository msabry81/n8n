# n8n project website — GitHub Pages

This static site is prepared for the repository path `https://msabry81.github.io/n8n/`.

## Files
- `index.html` — public homepage
- `privacy-policy.html` — privacy policy
- `terms-of-service.html` — terms of service
- `access.html` — access explanation (not a real login page)
- `assets/styles.css` — responsive styling
- `assets/app-icon.svg` — shared project icon and browser favicon

## Publish
1. Review every policy statement against the actual workflow and hosting setup.
2. Upload/replace these files in the root of the `n8n` GitHub repository, preserving the `assets` folder.
3. In GitHub, open **Settings → Pages** and ensure Pages is deployed from the intended branch and folder.
4. Wait for deployment, then test all URLs in a private/incognito browser window.

## Review warning
The `access.html` page explicitly explains that there is no end-user login. If the app-review form requires a real login entry point, this page does not satisfy that requirement. Use the actual hosted app/login URL or a reviewer test account if login is required. Do not invent credentials or submit a policy page as the application's login URL.

The icon is an original project icon and does not use the official n8n logo. This site is not presented as the official n8n company website.
- `assets/app-icon.png` — 1024×1024 PNG version of the same project icon for platforms that require a PNG upload.
