Access the n8n workflow

How access and authorization work

This website is a public information and policy site. It does not create user accounts or collect login credentials. The automation is operated through an n8n instance configured by the project operator.

How to use the integration

  1. Obtain the workflow or service access instructions from the project operator.
  2. Open the n8n instance where the workflow is configured.
  3. Connect the relevant third-party account using that platform's official authorization process, if the workflow requires it.
  4. Review the requested permissions and run the workflow only after you understand what it will do.
For the reviewer: This project currently has no end-user login because access is configured in the operator's n8n environment. If your app-review process requires users to sign in to a hosted application, this page is not a substitute for a real login entry point. Publish the actual application/login URL or provide a valid reviewer test account as required. Do not submit this website as a login URL unless it accurately represents the application's access flow.

Read the n8n Privacy Policy and n8n Terms of Service before authorizing any workflow.
